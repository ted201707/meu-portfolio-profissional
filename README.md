Meu Portfólio Profissional
Sobre o projeto

Este projeto foi desenvolvido como atividade prática da disciplina de Design Profissional e da trilha GitHub Foundations.

O objetivo é apresentar minha identidade profissional, minhas habilidades e alguns projetos desenvolvidos durante minha formação.

Objetivos
Praticar o uso do Git e GitHub;
Utilizar branches para desenvolver alterações;
Registrar alterações por meio de commits;
Utilizar Pull Requests;
Organizar informações profissionais;
Criar uma base para um portfólio pessoal.
