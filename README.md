
# Meu Portfólio Profissional

## 📌 Sobre o projeto

Este projeto foi desenvolvido como atividade prática da disciplina de **Design Profissional**, juntamente com a trilha **GitHub Foundations**.

O objetivo é apresentar minha identidade profissional, minhas habilidades e alguns projetos desenvolvidos durante minha formação em Análise e Desenvolvimento de Sistemas.

## 🎯 Objetivos

- Praticar o uso do Git e GitHub;
- Utilizar branches para desenvolver alterações;
- Registrar alterações por meio de commits;
- Utilizar Pull Requests;
- Praticar o processo de merge;
- Organizar informações profissionais;
- Criar uma base para um portfólio pessoal.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- Git
- GitHub


### Arquivos principais

**index.html**
Página principal do portfólio profissional.

**style.css**
Arquivo responsável pela estilização e organização visual da página.
